## 🚀 Featured Project

### [TECO — Thread-Less Ephemeral Context Orchestration](https://github.com/jemeepatel045/TECO)

A C++17 backend-systems project for short-lived, token-keyed session state.

**Tech:** C++17 · POSIX Sockets · Redis · Docker · CMake · Python · GitHub Actions

**Highlights:**

- Custom HTTP/1.1 server built with C++17 and POSIX sockets
- TTL-based ephemeral session management
- In-memory and Redis storage backends
- Shared state across multiple TECO processes
- Docker Compose deployment with two API instances and Redis
- REST API for session management
- Request metrics with average, P50, P95, and P99 latency
- Liveness and Redis-aware readiness checks
- Graceful SIGINT and SIGTERM shutdown
- Automated Redis outage and recovery testing
- GitHub Actions CI and Docker resilience validation

🏷️ **Latest Release:** [TECO v1.0.0](https://github.com/jemeepatel045/TECO/releases/tag/v1.0.0)
